## Модуль Terraform для создания бессерверного HTTP API на базе Yandex Managed Service for YDB

Этот модуль позволяет быстро и легко создать бессерверный HTTP API для работы с данными, хранящимися в [Yandex Managed Service for YDB](https://yandex.cloud/services/ydb).


API состоит из [API Gateway](https://cloud.yandex.ru/services/api-gateway), [Yandex Function](https://cloud.yandex.ru/services/functions) с [коннектором DynamoDB](https://bb.yandex-team.ru/users/vvkuz/repos/apigw-dynamodb-connector) и [YDB](https://yandex.cloud/services/ydb).

Для начала работы изучите [эти примеры](examples).
